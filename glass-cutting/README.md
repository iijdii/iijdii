# Glaszuschnittplan — Inженерный модуль раскроя стекла

Инженерный модуль CRM для стекольного производства. По координатам конструкции
автоматически рассчитывает реальные размеры стёкол, проверяет контрольные
диагонали/замеры, подбирает оптимальную заготовку, строит SVG-чертежи и
генерирует печатный лист раскроя (**Glaszuschnittplan**, A4, немецкие подписи).

## Состав

| Файл | Назначение |
|------|-----------|
| `glass-engine.js` | Чистый расчётный движок (геометрия, MBR, площади, отход, контроль замеров). Работает в браузере и в Node. |
| `glass-render.js` | Генерация SVG-чертежей, итоговой таблицы и готового HTML (печать A4). |
| `index.html` | Интерактивный редактор: ввод H / низ / верх / контрольные замеры → чертёж и лист раскроя в реальном времени. |
| `generate.js` | CLI: из JSON-файла создаёт готовый `plan.html`. |
| `example.json` | Пример входных данных. |
| `test.js` | Быстрые тесты движка. |

## Быстрый старт

### В браузере
Откройте `index.html`. Введите высоту, размеры по низу и по верху,
при необходимости контрольные замеры — нажмите **Berechnen**. Кнопки
**Drucken** (печать A4) и **HTML** (скачать файл).

### Из командной строки
```bash
node generate.js example.json plan.html
```
Создаст `plan.html` и выведет краткий отчёт в консоль. Без аргументов
читает `example.json` и пишет `plan.html`.

### Тесты
```bash
node test.js
```

## Входные данные

```json
{
  "meta":    { "project": "Seitenwand", "order": "ANF-2026-001", "date": "2026-06-08" },
  "H":       2170,
  "bottom":  [1370, 1280, 1080, 1070],
  "top":     [55, 55, 215, 50],
  "controls":[ { "diagAC": 2540, "left": 2170 }, null, { "left": 3300 }, null ],
  "options": { "measureTolerance": 30, "longSideFactor": 1.3 }
}
```

- **H** — высота конструкции (мм).
- **bottom / top** — размеры по низу и по верху (мм). Длины массивов должны
  совпадать (= числу стёкол).
- **controls[i]** — необязательные контрольные замеры стекла `i+1`. Ключи:
  `bottom`, `top`, `left`, `right`, `diagAC`, `diagBD`. `null` — без контроля.
- **options.measureTolerance** — допуск (мм). Δ больше допуска ⇒
  «**NACHMESSEN ERFORDERLICH**» (ТРЕБУЕТСЯ ПЕРЕМЕР).
- **options.longSideFactor** — порог длинной стороны (× H) для выбора
  повёрнутой заготовки.

## Алгоритм

1. **Узлы низа** `P0=(0,0)`, `Pi=(ΣB, 0)` и **узлы верха** `Q0=(0,H)`,
   `Qi=(ΣT, H)` — накопительные суммы.
2. **Стекло i** — четырёхугольник `A=Pᵢ`, `B=Pᵢ₊₁`, `C=Qᵢ₊₁`, `D=Qᵢ`.
3. **Стороны** по формуле расстояния: низ `AB`, право `BC`, верх `CD`, лево `DA`.
   **Диагонали** `AC`, `BD`.
4. **Контроль замеров**: |расчёт − замер| > допуск ⇒ перемер.
5. **Тип заготовки**:
   - длинная сторона < `1.3·H` → обычная заготовка (осевой bounding box);
   - длинная сторона > `1.3·H` → **Minimum Bounding Rectangle** (повёрнутый
     прямоугольник минимальной площади, метод rotating calipers по выпуклой
     оболочке).
6. **Площади** (формула Гаусса/шнуровки) и **процент отхода**
   `(S_заготовки − S_стекла) / S_заготовки`.
7. **SVG** на каждое стекло: серый пунктир — заготовка, синяя заливка —
   стекло, оранжевые линии — резы, бемаżировка всех сторон и заготовки,
   подпись отхода. Бемаżировки выносятся за контур (не накладываются), поле
   SVG растёт автоматически.
8. **Итоговая таблица** (Schnittliste) и готовый HTML с печатью A4 и
   немецкими подписями для производства.

## Использование движка как библиотеки

```js
const Engine = require('./glass-engine.js');
const Render = require('./glass-render.js');

const plan = Engine.computePlan({ H: 2170, bottom: [...], top: [...] });
const html = Render.buildHTML(plan, { project: 'Seitenwand' });
// plan.glasses[i] → sides, diagonals, blank, areas, wastePercent, control
```

В CRM движок подключается к данным заявки (см. `docs/anfrage-fields.txt`):
`hoehe_cm`/`breite_cm` и замеры из этапа `aufmass_gemacht`.
